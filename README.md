# MK Red Sea

Marketing site for **Mootaz Kafy**, PADI Scuba Instructor based in Sharm El Sheikh, Red Sea.

## Tech

Plain static HTML/CSS/JS — no framework, no build step, no dependencies to install.
Deployed on [Vercel](https://vercel.com) as a zero-config static site: `index.html` at the
project root is served at `/` automatically, no `vercel.json` needed.

## Local development

From the project root:

```bash
python3 -m http.server 8000
```

Then open in your browser:

- `http://localhost:8000/` — the main site
- `http://localhost:8000/alt/` — the alternate dark/bold design (see below)

Stop the server with `Ctrl+C` in that terminal when you're done.

If port 8000 is already in use, either free it (`lsof -ti:8000 | xargs kill`) or just
pick a different port, e.g. `python3 -m http.server 8123` and browse to
`http://localhost:8123/` instead.

## Alternate design

`alt/index.html` is a second design option, built to compare against the main site —
same Mootaz content, a bolder dark/monochrome visual style (inspired by
flowstatedivers.com's look) with a light/dark theme toggle and a full-screen nav
overlay. It's self-contained (`alt/assets/`), doesn't touch anything at the project
root, and is reachable at `/alt/` both locally and once deployed. Its photos are
free-license Unsplash stock (credited in `alt/assets/photos/SOURCES.md`), color-graded
by `alt/scripts/grade-photos.py`; its mono logo variants are generated by
`alt/scripts/make-mono-logo.py` from the same master logo file the main site uses.

## More design options

Each is a self-contained static site (its own `assets/`, with `<base href="/altN/">`
so it works at both `/altN` and `/altN/` on Vercel), using the same content, logo and
photos as the main site. `/designs/` shows them all side by side with screenshots for
the client to compare.

- `alt2/` — the bold alt design with a blue accent instead of red
- `alt3/` — alt2 with the full-colour logo enlarged and floating over the header
- `alt4/` — **Editorial**: travel-magazine layout, serif type, sand/sea/rust palette
- `alt5/` — **Social profile**: Instagram-style profile page, phone-width, docked DM button
- `alt6/` — **Depth journey**: the page darkens as you scroll, with a live depth gauge
- `alt7/` — **Dive centre**: conversion-focused layout with trust strip, how-to-book,
  reviews (placeholders — add real ones before going live) and FAQ

alt4–alt7 use the colour-corrected photos; the "Best for" lines, booking steps and FAQ
wording in alt7 were written from the existing bio and should be checked with the client.

## Brand assets — logo & favicon

The logo and favicon are the client's own brand assets and are important to him — **do
not redesign, recolor, or replace them without his sign-off.**

- `assets/logo/mk-redsea-badge-original.png` — the master/archival copy, extracted
  at full resolution exactly as supplied.
- `assets/logo/mk-redsea-badge.png` — a resized copy of the same artwork (no
  redesign), used on the page for faster load times.
- `assets/logo/mk-redsea-badge-cropped.png` — the same artwork with the empty
  transparent border trimmed off (the supplied file's badge only fills ~50% of its
  canvas, so it always looked half-size). Made by `scripts/crop-logo.py`; used by
  the main site and alt3–alt7.
- `assets/favicon/favicon-32.png`, `favicon.ico`, `apple-touch-icon.png` — extracted
  as-is from the original design, not newly created icons.

Both were originally embedded as base64 data URIs in `mkredsea-holding.html` /
`mkredsea-holding2.html`. `scripts/extract-assets.py` decodes them back out to real
files; re-run it if the extracted copies ever need regenerating from the holding page.

The section icons in `assets/icons/` (`icon-turtle.png`, `icon-fish.png`, `icon-coral.png`,
`icon-sun.png`, `icon-wave-badge.png`) are cropped directly out of the same logo artwork —
not redrawn — so they match the client's actual logo exactly.

## Instagram

The "DM to Book" call-to-action across the site all points to a single constant,
`INSTAGRAM_URL`, defined once in `assets/js/main.js`. Update the handle there if it
ever changes — every button/link on the page updates automatically.
